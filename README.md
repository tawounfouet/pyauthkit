# PyAuthKit

Framework-agnostic Python authentication engine.

> Status: specification and implementation bootstrap. No authentication mechanism is implemented or security-qualified yet.

Roadmap: milestones M0-M9 (`27_PYAUTHKIT_IMPLEMENTATION_ROADMAP.md`), beginning with M0 and PR-01. Authentication and authorization remain separate responsibilities.

Do not use this repository for production authentication until the relevant security qualification gates are complete.
